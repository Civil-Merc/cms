# CivilMerc CMS

Back-office tool for updating the CivilMerc website: services, projects, About Us, and Contact Us.

Sign in with your admin account, edit content and images, then publish when it is ready to go live.

**Website integration:** see [docs/public-cms-api.md](docs/public-cms-api.md) for how the public site loads that content.

Authorized staff only.
